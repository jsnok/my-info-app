# 비밀 노트 🔐

개인 정보를 `항목 : 내용` 형태로 정리해 두고 휴대폰에서 바로 확인하는 앱입니다.
(설치형 웹앱 — PWA. 앱스토어 없이 홈 화면에 추가해서 일반 앱처럼 씁니다.)

## 기능
- **엑셀처럼 칸을 탭해서 바로 수정** — 항목 이름 칸 → Enter → 내용 칸으로 이동
- **＋ 항목 추가 / ＋ 새 분류 추가** (분류 이름·아이콘 변경 가능)
- **계정 정보** — 사이트마다 아이디 / 비밀번호 칸이 나뉘어 있고 각각 복사 가능
- **가리기(🔒)** — 여권번호·주민번호·계좌번호 등은 `••••••`로 가려 두고 👁로 잠깐 보기
- **📋 복사**, 🔍 검색, 분류별 보기
- **✎ 편집 모드** — 순서 변경(▲▼), 삭제, 가리기 설정
- **백업/복원** — 메뉴(⋯)에서 JSON 파일로 내보내기·불러오기
- 오프라인에서도 동작

## 개인정보 보관 위치
입력한 내용은 **휴대폰 브라우저 저장소(localStorage)에만** 저장됩니다.
서버나 GitHub에는 올라가지 않으며, 이 저장소에는 앱 코드만 있습니다.
브라우저 데이터를 지우면 내용도 사라지므로 메뉴 → **백업 파일 저장**을 가끔 해 두세요.

## 휴대폰에 설치하기
1. GitHub Pages 주소(예: `https://<아이디>.github.io/my-info-app/`)를 휴대폰에서 엽니다.
2. **iPhone (Safari)**: 공유 버튼 → *홈 화면에 추가*
   **Android (Chrome)**: ⋮ 메뉴 → *앱 설치* 또는 *홈 화면에 추가*

## PC에서 미리 보기
```bash
python -m http.server 8765
```
그 후 브라우저에서 http://localhost:8765 접속.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면·기능) |
| `manifest.json` | 홈 화면 설치 정보 (이름, 아이콘, 색상) |
| `sw.js` | 오프라인 실행용 캐시 |
| `icon*.png`, `icon.svg` | 앱 아이콘 |
